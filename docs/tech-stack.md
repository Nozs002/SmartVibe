# SmartVibe Tech Stack

## 1. Frontend

- React JavaScript
- HTML
- CSS
- có thể dùng Bootstrap hoặc MUI để tăng tốc làm giao diện

## 2. Backend

- Spring Boot
- Spring Web
- Spring Data JPA
- Lombok
- MySQL Connector

## 3. Database

- MySQL
- chạy bằng Docker Compose

## 4. Công cụ hỗ trợ

- MySQL Workbench
- Postman
- VS Code hoặc IntelliJ IDEA
- Git và GitHub

## 5. Hướng triển khai

- frontend chạy local
- backend chạy local
- database chạy bằng Docker

## 6. Mục tiêu kỹ thuật

- dễ cài đặt
- dễ debug
- phù hợp cho người mới học full-stack
- đủ tốt để hoàn thành MVP trong khoảng 2 tháng
